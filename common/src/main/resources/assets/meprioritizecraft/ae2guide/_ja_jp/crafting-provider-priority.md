# クラフトプロバイダー優先度

AE Improved Crafting Prioritization は、AE2方式のプロバイダー優先度をクラフトプロバイダーに適用します。

対象:
- AE2のPattern Provider
- ExtendedAEのAssembler Matrix

## 変更される挙動

- 優先度が影響するのはクラフトジョブ全体ではなく、各パターンプロバイダーです。
- 同じ出力を作れるプロバイダーが複数ある場合は、数値が高い優先度から先に使われます。
- 既定値は `0` です。
- 個別設定がないプロバイダーは優先度 `0` として扱われます。
- 優先度が同じ場合は、Applied Energistics 2 の通常の選択ロジックが使われます。
- 最上位優先度のプロバイダーだけで要求数を満たせない場合、プランナーは優先度順で下位候補へ継続し、複数プロバイダーを組み合わせて処理します。

## 動作例

優先度 `100` のプロバイダーAと、優先度 `10` のプロバイダーBが同じ出力を作れる場合、まずAが使われます。  
Aの素材が途中で不足したら、残り要求分はBが引き継いで処理します。
