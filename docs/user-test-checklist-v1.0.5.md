# ユーザーテストチェックリスト — v1.0.5

このチェックリストは、v1.0.4で報告された以下2件の不具合修正を確認するためのものです。

- 優先度設定UIは表示されるが、実際には効かない・低優先度へのフォールバックが発生しない
- ゲームを終了すると優先度設定UIに入れた数値が消える

対象ローダー: Forge 1.20.1 / NeoForge 1.21.1 / NeoForge 26.1.2（3環境すべてで確認してください）

## 事前準備

- [ ] ExtendedAE、AE2（transitive）、JEI、Jade、GuideME を対象ローダー・バージョンに合わせて導入した
- [ ] Assembler Matrix を1基以上組み立てた（複数パターン登録可能な状態）
- [ ] 同一アウトプットを作れる Pattern Provider（低優先度側）も1基用意した

## 1. 基本機能の動作

- [ ] Assembler Matrix の優先度設定UIを開ける（クラッシュ・フリーズなし）
- [ ] 優先度に任意の数値（例: 100）を入力し保存できる
- [ ] Assembler Matrix（高優先度）と Pattern Provider（低優先度、デフォルト0）が同じアイテムを作れる状態で、そのアイテムをオーダーする → **Assembler Matrix側が使われる**
- [ ] Assembler Matrixの入力材料を空にした状態で同じアイテムをオーダーする → **Pattern Provider側へフォールバックされる**
- [ ] Assembler Matrixが一部数量のみ供給可能な状態で複数個オーダーする → **不足分がPattern Providerで補われる（部分フォールバック）**

## 2. 終了時の挙動

- [ ] Assembler Matrixに優先度（例: 200）を設定した
- [ ] ゲームを終了する（ワールドを抜ける、またはクライアントを終了する）
- [ ] 再度ゲームを起動し、同じワールドに入る
- [ ] Assembler Matrixの優先度設定UIを開く → **設定した数値（200）がそのまま残っている**
- [ ] Assembler Matrixに登録していたパターンが消えていない
- [ ] Assembler Matrixの入力/出力インベントリの中身が消えていない
