# AE2: Improved Crafting Prioritization
Это дополнительный мод для AE2.
Этот мод улучшает поведение приоритета крафта на уровне провайдера для МЭ поставщик шаблонов.

## Зависимые моды
### Обязательно
- [Applied Energistics 2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2)
### Опционально
- [ExtendedAE](https://www.curseforge.com/minecraft/mc-mods/ex-pattern-provider)

## Функция 1: Улучшение выбора ингредиентов
### Поведение AE2
- Вы можете зарегистрировать несколько рецептов для одного и того же результата, например `8x Дубовые доски -> Сундук` и `8x Вишнёвые доски -> Сундук`.
- Если установить приоритет крафта 1 на МЭ поставщик шаблонов для рецепта Oak Planks и 2 для рецепта Cherry Planks, система автокрафта сначала проверит **Cherry Planks**, затем Oak Planks.

| Кол-во в хранилище<br>Дубовые доски | Кол-во в хранилище<br>Вишнёвые доски | Заказ | Выполнение крафта |
| --- | --- | --- | --- |
|  8 |  0 | 1x Сундук | Работает с 8x Дубовые доски |
|  0 | 24 | 3x Сундук | Работает с 24x Вишнёвые доски |
|  8 | 16 | 3x Сундук | :no_entry: **Не хватает ингредиентов!**<br>Нужно ещё 8x Вишнёвые доски |

### Поведение этого мода
Этот мод решает такую ситуацию. Вы сможете заказать 3 Сундук при 8x Дубовые доски и 16x Вишнёвые доски.
#### Сценарий автора мода
- Заказывать много железных слитков или Osmium Ingots в **Mekanism**, а также иметь **Mystical Agriculture**.
- Я бы поставил более высокий приоритет для Шаблона крафта с Essence и более низкий для Шаблона плавки с dusts.

## Функция 2: Сборочная матрица получает приоритет
### Поведение ExtendedAE
У Сборочная матрица из ExtendedAE нет меню приоритета.
### Поведение этого мода
Теперь оно есть.
#### Сценарий автора мода
Мне очень нравится Сборочная матрица, и я помещаю туда много рецептов. Детали не важны; я ставлю приоритет 1000 для таких рецептов.
- То же, что я написал выше, должно работать хорошо: Essence против smelting dusts.
- Также работает для Кварца цертуса. Сначала используйте Essence, затем запустите цикл с Crusher и Реакционной камерой для остального.
